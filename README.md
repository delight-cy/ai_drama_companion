# 视频资源说明

本仓库**不包含**体积较大的示例正片 `qingyvnian.mp4`（避免超过 GitHub 单文件大小限制）。

## 本地运行前

请将你的演示用视频文件放到本目录，并命名为：

- `qingyvnian.mp4`

或修改 `ai_drama_companion.html` 中 `<video>` 的 `<source>` 路径。

## 比赛 / 在线演示

可选用以下方式之一：

1. 在 README 中附上你的演示视频链接（B站、腾讯会议录屏、网盘等）。
2. 使用 [Git LFS](https://git-lfs.github.com/) 跟踪大文件（需仓库开启 LFS 配额）。
3. 将页面部署到支持大静态资源的平台（视平台限制而定）。
